> **이 저장소의 지침이다**(2026-09-23 착수 · 2026-09-24 템플릿에서 라이브러리로 전환).

> - **봇 일반의 설계는 [`BOT.md`](./BOT.md)에 있다** — 테넌트·계정·선언·상태·갈리는 것·
>   코어와 붙는 법, 그리고 **봇을 짓는 법**. 봇 저장소는 그 파일을 복사하지 않는다.
> - **이 저장소는 공개다**(2026-09-24). 봇들은 비공개로 남는다 — 공개인 것은 라이브러리뿐이고,

## 이 파일과 `BOT.md`가 갈린 까닭

**독자가 다르다.** `BOT.md`는 **봇을 짓는 사람**이 읽고(어느 봇에도 속하지 않는 설계),
이 파일은 **이 저장소를 여는 사람**이 읽는다(라이브러리 자신을 어떻게 손질하는가).

| 파일 | 누구의 것 | 봇 저장소에서 |
|---|---|---|
| `.claude/BOT.md` | **라이브러리** | 설치된 패키지나 GitHub에서 읽는다. **사본이 없으니 어긋날 일도 없다** |
| `.claude/PROJECT.md` | **그 저장소** | 자기 것을 쓴다. 봇 일반의 것을 옮겨 적지 않고 `BOT.md`를 가리킨다 |

> 처음에는 봇 일반의 설계를 이 파일에 두었다. 그때는 봇이 이 저장소를 **포크**했으므로
> **`git merge upstream/main`이 늘 충돌했다** — 같은 파일을 양쪽이 자기 것으로 삼기
> 때문이다(2026-09-23에 에코가 첫 merge에서 바로 걸렸고, 2026-09-24에 순회 안내를 여기
> 적었다가 두 포크가 또 걸렸다). **의존으로 바꾸면서 그 충돌 자체가 사라졌지만**, 가름은
> 그대로 옳다: 독자가 다른 글이다.

## 이 저장소가 하는 일

**의존되는 것.** 여기서 짓는 것은 *어느 봇에도 속하지 않는 것*이고, 봇은 이것을 **git 태그
의존**으로 쓴다 — `github:oxmhpark/miniwiki-bot#v0.3.0`(`BOT.md`의 *봇을 짓는 법*).

| 무엇 | 어디 |
|---|---|
| **공개 API** | `src/index.ts` — 봇이 가져다 쓰는 것은 여기 적힌 것뿐이다 |
| 내보내지 않는 것 | `web.ts` · `pages.ts` · `auth.ts` · `markdown.ts` — 화면과 문은 이 라이브러리가 통째로 진다 |
| **새 봇의 견본** | `template/` — `Dockerfile` · `docker-compose*.yml` · `Procfile` · `manifest.json` · `main.ts`. 새 봇이 통째로 베낀다 |
| 검사 | `web.test.ts`(화면 전 구간) · `markdown.test.ts`. **봇의 검사는 봇 저장소에 있다** |

## 판을 내는 법

**판은 태그다.** 레지스트리에 올리지 않으므로 `npm publish`가 없다 — 봇은 태그를 가리킨다.

```sh
npm run typecheck && npm test              # 도커로 돈다 — 이 기계에 node가 없다
npm version minor                          # package.json과 태그가 함께 오른다
git push --follow-tags origin main
```

**봇은 태그로 받고 락파일에는 커밋 sha가 박힌다** — 태그를 옮겨도 봇은 받던 것을 계속 받는다.
그래서 **낸 태그는 옮기지 않는다**: 고칠 것이 있으면 다음 판을 낸다.

**`dist`를 커밋하지 않는다.** 봇이 설치할 때 `prepare`가 `tsc`를 돌려 만든다 — 그래서
`typescript`가 `devDependencies`에 있어야 한다.

## 공개 API를 늘리거나 줄일 때

**봇이 라이브러리 파일을 고쳐야 한다면 그것은 이 라이브러리의 결함이다.** 봇에는 그 파일이
아예 없으므로 고칠 수도 없다 — 2026-09-23에 채토가 *사람이 키를 맡기는 폼*에서 그랬고, 그
답이 `intake.ts`였다.

**타입을 늘리면 봇의 검사가 깨진다**(`BotContext`에 필드를 더하면 봇의 가짜 컨텍스트가
걸린다). 그것은 정상이고, **언제 겪을지는 봇이 판을 올리며 고른다**.
